1. What is Version Control?
Version control tracks changes in my code over time. It lets me save progress, undo mistakes, and work with others safely.

​2. What is Git?
Git is a free tool on my computer that saves snapshots of my code and tracks changes locally.

​3. What is GitHub?
GitHub is a website where I upload my Git projects to back them up, share them, or work with a team online.

​4. What is Git Bash?
Git Bash is a terminal app for Windows that lets me type Git and Linux commands to control my files.
​
5. What are the Parts of GitHub?
​Repository: A project folder that holds all my files and history.
​Commit: A saved point or snapshot of my code changes.
​Branch: A separate copy of the project to test new code safely.
​Pull Request: A request to merge branch changes into the main code.
​Issue: A post to track bugs, tasks, or feature ideas.

​6. What are the Stages of Git/GitHub?
​Working Directory: The local folder where I write and edit my code.
​Staging Area: The prep area where I choose files using git add.
​Local Repository: The hidden folder on my PC where changes are saved using git commit.
​Remote Repository: The online GitHub storage where I upload code using git push.
