## 1. What is Version Control?
Version control is a system that tracks and manages changes made to files or source code over time. It allows developers to keep a history of their work, revert to previous states if something breaks, and collaborate easily without overwriting each other's work.

## 2. What is Git?
Git is a free, open-source, and distributed version control system installed on your local computer. It records snapshots of your project code, allowing you to manage branches, track modifications, and keep your code history organized locally.

## 3. What is GitHub?
GitHub is a cloud-based hosting platform for Git repositories. It allows developers to store their local Git projects online, collaborate with team members, share code publicly or privately, and host live web pages using GitHub Pages.

## 4. What is Git Bash?
Git Bash is a command-line application designed for Windows users. It provides a Unix-like terminal environment that allows developers to execute `git` commands as well as standard bash commands on their machines.

## 5. What are the Parts of GitHub?
- **Repository:** The digital space or folder where all project files, images, and commit history are stored.
- **Commit:** A saved snapshot of the project changes recorded permanently in the repository.
- **Branch:** An independent line of development used to test new features without affecting the main code.
- **Pull Request:** A proposal sent to merge changes from one branch into another after code review.
- **Issue:** A tracking tool used to log bugs, request features, or manage tasks in a project.

## 6. What are the Stages of Git/GitHub?
1. **Working Directory:** The local directory where you actively edit, create, or modify your project files.
2. **Staging Area:** The temporary preview area where you organize and select specific file changes using `git add` before committing them.
3. **Local Repository:** The internal `.git` directory on your computer where committed snapshots are saved permanently using `git commit`.
4. **Remote Repository:** The online project hosted on GitHub where local commits are uploaded using `git push` for cloud backup and sharing.
